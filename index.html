What it does

Counter class in JavaScript is a simple JavaScript class that builds a counter widget inside any container element. It keeps track of its own count, creates its own buttons, and updates the display automatically. The count never goes below 0 — the Decrement and Reset buttons go grey when you hit zero.

StepCounter is a subclass that extends Counter. Instead of going up/down by 1, it jumps by a custom step value you set when creating it.

How To Use

Example HTML container markup

<div id="my-counter" class="counter"></div>

Example instantiation code

<script type="module" defer src="js/main.js"></script>

Explanation of parameters

import { Counter } from './counter.js';
import { StepCounter } from './counter.js';

new Counter("#my-counter", 0);

new StepCounter("#my-step-counter", 0, 5);
